A Comprehensive Guide to R for Data Science

This guide provides an extensive summary of the most common procedures and code examples used in a typical data science workflow in R. It is designed for undergraduate or postgraduate students who have some programming familiarity but are new to R and statistics. The content is synthesized from "R for Data Science" by Dan Toomey, "R Cookbook" by Paul Teetor, and "Visualization and Imputation of Missing Values" by Matthias Templ.

Part 1: R Fundamentals & Setup

Before analyzing data, it's essential to master the basics of the R language and its environment.

1.1. Basic Operations and Variables

  • Setting Variables: In R, you store values in variables using the assignment operator <-.
    # Assign the value 5 to the variable x
    x <- 5

    # Perform a calculation and store the result
    y <- 10
    z <- (x + y) / 2

    # To see the value, just type the variable name
    z
  • Creating Vectors: A vector is a one-dimensional array that holds a sequence of elements of the same type. The c() (combine) function is fundamental for creating vectors.
    # Numeric vector
    numeric_vec <- c(1, 2.5, 4.8, 10)

    # Character vector (strings)
    character_vec <- c("alpha", "beta", "gamma")

    # Logical vector
    logical_vec <- c(TRUE, FALSE, TRUE, TRUE)
  • Vector Arithmetic: R performs arithmetic operations on vectors element-by-element. This is a powerful feature called vectorization.
    v1 <- c(10, 20, 30)
    v2 <- c(2, 4, 6)

    v1 / v2 # Output: [1] 5 5 5

    # Operations with a single number (scalar) apply to every element
    v1 + 100 # Output: [1] 110 120 130

1.2. Data Structures

  • Data Frames: A data frame is a two-dimensional, table-like structure where columns can be of different types. It is the most common way to store datasets in R.
    # Create a data frame from vectors
    patient_data <- data.frame(
     ID = c("P01", "P02", "P03"),
     Age = c(25, 34, 29),
     Treatment = c("A", "B", "A"),
     Score = c(85.1, 92.4, 78.9)
    )
  • Lists: A list is a flexible container that can hold a mix of different data types and structures, including other lists or data frames.
    my_list <- list(
     name = "John Doe",
     age = 30,
     scores = c(85, 92, 78),
     is_student = TRUE,
     metadata = data.frame(id=1, group="control")
    )
  • Factors: Factors are used to represent categorical variables. R treats them specially in statistical models and plots.
    # Create a factor from a character vector
    treatment_factor <- factor(c("Control", "Treated", "Treated", "Control"))

    # View the levels (unique categories)
    levels(treatment_factor)

1.3. Data Input and Output

  • Reading a CSV File: The read.csv() function reads data from a CSV file into a data frame.
    my_data <- read.csv("path/to/your/file.csv")

    # If the file uses semicolons instead of commas
    my_data_semi <- read.csv2("path/to/your/file.csv")
  • Reading a Tabular Data File: For more general text files (e.g., tab-separated), use read.table().
    # Read a tab-separated file with a header
    my_data_tsv <- read.table("file.tsv", header=TRUE, sep="\t")
  • Writing to a CSV File: You can save a data frame to a CSV file using write.csv().
    write.csv(patient_data, file="output.csv", row.names=FALSE)

Part 2: Data Wrangling and Preparation

This section covers essential techniques for cleaning, transforming, and preparing your data for analysis.

2.1. Handling Missing Data (NA)

Missing values (NA) are a common problem. Handling them correctly is crucial for sound analysis.

Understanding Missing Data Mechanisms
  • MCAR (Missing Completely at Random): The missingness is random and does not depend on any other variable.
  • MAR (Missing at Random): The probability of a value being missing depends on other observed variables in the dataset. This is a common and manageable scenario.
  • MNAR (Missing Not at Random): The probability of a value being missing is related to the unobserved value itself. This is the most difficult case to handle.
Visualizing Missing Data with VIM

Before imputing (filling in) missing values, it's essential to understand their patterns.

  • Aggregation Plot: The aggr() function creates a plot showing the proportion of missings in each variable and the most frequent combinations of missing values.
    # install.packages("VIM")
    library(VIM)
    data(sleep, package = "VIM")
    aggr(sleep, prop=TRUE, numbers=TRUE)
  • Margin Plot: A scatterplot that also shows the distribution of missing values in the margins, helping to identify MAR patterns.
    marginplot(sleep[, c("Dream", "NonD")])
Imputation: Filling in Missing Values

Simply deleting rows with missing values can bias your results. Imputation is often a better strategy.

  • k-Nearest Neighbor (kNN) Imputation: An intuitive method that finds the 'k' most similar complete observations (neighbors) and uses their values to impute the missing value.
    sleep_imputed_knn <- kNN(sleep, k=5)
  • Multiple Imputation by Chained Equations (MICE): A powerful, flexible approach that creates multiple complete datasets to properly account for the uncertainty of imputation.
    # install.packages("mice")
    library(mice)
    imputed_data <- mice(sleep, m=5, method='pmm', seed=500)
    complete_sleep_data <- complete(imputed_data, 1) # Get the first complete dataset

2.2. Data Transformation and Manipulation

  • Selecting Rows and Columns with subset():
    # Select rows where Age is greater than 30
    older_patients <- subset(patient_data, subset = (Age > 30))

    # Select only the ID and Score columns
    id_and_score <- subset(patient_data, select = c(ID, Score))
  • Applying a Function to Groups of Data with tapply():
    # Calculate the mean score for each treatment group
    mean_scores_by_group <- tapply(patient_data$Score, patient_data$Treatment, mean)
  • Sorting a Data Frame: Use the order() function inside the square brackets.
    # Sort patient_data by Age in ascending order
    sorted_data <- patient_data[order(patient_data$Age), ]

    # Sort by Age in descending order
    sorted_data_desc <- patient_data[order(-patient_data$Age), ]

2.3. Text Mining with tm

  • Text Mining Workflow:
    # install.packages("tm")
    library(tm)

    docs <- c("This is the first document.", "This document is the second document.")
    corpus <- Corpus(VectorSource(docs))

    corpus <- tm_map(corpus, content_transformer(tolower))
    corpus <- tm_map(corpus, removePunctuation)
    corpus <- tm_map(corpus, removeWords, stopwords("english"))

    dtm <- DocumentTermMatrix(corpus)
    inspect(dtm)

Part 3: Data Analysis and Exploration

This phase involves exploring your data to find patterns, relationships, and insights through statistics and visualization.

3.1. Descriptive Statistics: Numerical Summaries

  • Summarizing Data: The summary() function provides a quick statistical overview of a data frame or vector, including mean, median, quartiles, and min/max for numeric data, and frequency counts for factors.
    # Get a summary of the built-in 'mtcars' dataset
    summary(mtcars)
  • Calculating Relative Frequencies: To find the proportion of data that meets a certain condition, use mean() on a logical expression.
    # Calculate the proportion of cars with more than 150 horsepower
    mean(mtcars$hp > 150)
  • Creating Crosstabulations (Contingency Tables): Use table() to count occurrences of categories. For two or more variables, it creates a contingency table that shows the frequency distribution of the variables. This is fundamental for analyzing relationships between categorical variables.
    # Use the built-in HairEyeColor dataset
    data(HairEyeColor)

    # Create a 2-way contingency table of Hair Color vs. Eye Color for Males
    male_data <- HairEyeColor[,, "Male"]
    hair_eye_table <- table(male_data)

    # A more direct way to create a 2-way table from columns in a data frame
    # This creates a table of car cylinders vs. number of gears
    cyl_gear_table <- table(mtcars$cyl, mtcars$gear)
    print(cyl_gear_table)

3.2. Descriptive Statistics: Graphical Methods

Visualizing data is key to understanding its structure and identifying patterns.

  • Histograms with Density Overlays: Visualize the distribution of a single numeric variable. You can overlay a smoothed density curve to better see the shape.
    # Create a histogram of MPG, scaling it to show probability densities
    hist(mtcars$mpg, prob=TRUE, breaks=10,
        main="Histogram of MPG with Density Curve", xlab="Miles Per Gallon")

    # Add a smoothed density line
    lines(density(mtcars$mpg), col="red", lwd=2)
  • Box Plots: Excellent for comparing distributions across different groups.
    # Use a formula to create one box plot for each cylinder group
    boxplot(mpg ~ cyl, data = mtcars,
           main="MPG by Number of Cylinders",
           xlab="Number of Cylinders",
           ylab="Miles Per Gallon")
  • Scatter Plots: The standard way to visualize the relationship between two numeric variables.
    plot(mtcars$wt, mtcars$mpg,
        main="Weight vs. MPG",
        xlab="Weight (1000 lbs)",
        ylab="Miles Per Gallon")

    # Add a linear regression line to the plot
    abline(lm(mpg ~ wt, data = mtcars), col = "red")
  • Scatterplot Matrices: To visualize the relationships between all pairs of numeric variables in a dataset simultaneously.
    # Create a scatterplot matrix for the first four (numeric) columns of the iris dataset
    pairs(iris[, 1:4], main = "Iris Data Scatterplot Matrix")
  • Mosaic Plots for Categorical Data: A graphical representation of a contingency table, where the area of each rectangle is proportional to the frequency of that cell. It's excellent for visualizing relationships between two or more categorical variables.
    # Use the table of hair and eye color created earlier
    mosaicplot(hair_eye_table, shade = TRUE, main = "Hair vs. Eye Color")

3.3. Correlation Analysis

Correlation measures the strength and direction of a linear relationship between two variables.

  • Calculating and Testing Correlation: cor() calculates the coefficient, while cor.test() also provides a p-value for significance.
    # Test the significance of the Pearson correlation between weight and mpg
    cor.test(mtcars$wt, mtcars$mpg, method="pearson")
  • Correlation for Non-Normal or Ordinal Data:
  • Spearman's Rho: Use for non-normal data or data with outliers.
    cor.test(mtcars$wt, mtcars$mpg, method="spearman")
  • Polychoric Correlation: Use for two ordinal variables.
    # install.packages("polycor")
    library(polycor)
    # polychor(ordered_var1, ordered_var2)
  • Visualizing Correlations with Correlograms:
    # install.packages("corrgram")
    library(corrgram)
    corrgram(iris[,1:4], order=TRUE, lower.panel=panel.shade,
            upper.panel=panel.pie, text.panel=panel.txt)

3.4. Hypothesis Testing

Hypothesis testing is a formal procedure for making statistical inferences. It involves a null hypothesis (H_0) and an alternative hypothesis (H_a). A small p-value (typically < 0.05) provides evidence to reject the null hypothesis.

  • One-Sample t-test: Tests if a sample mean is significantly different from a known or hypothesized population mean.
    t.test(mtcars$mpg, mu=20)
  • Two-Sample t-test: Tests if the means of two independent groups are different.
    t.test(mpg ~ am, data = mtcars)
  • One-Proportion Test: Tests if a sample proportion is different from a hypothesized population proportion.
    prop.test(x=60, n=100, p=0.5)
  • Chi-squared Test: Tests if two categorical variables are independent.
    tbl <- table(mtcars$cyl, mtcars$am)
    chisq.test(tbl)
  • Shapiro-Wilk Test for Normality:
    shapiro.test(mtcars$mpg)

Part 4: Modeling and Machine Learning

This is where you build predictive models to make sense of your data.

4.1. Regression Analysis

  • Multiple Linear Regression: Use the lm() function with multiple predictors.
    model <- lm(mpg ~ wt + disp + hp, data=mtcars)
    summary(model)
  • Diagnostic Plots: It's crucial to check the assumptions of your model.
    par(mfrow=c(2,2))
    plot(model)
    par(mfrow=c(1,1))

4.2. Clustering (Unsupervised Learning)

  • K-Means Clustering: Partitions the data into a pre-specified number of clusters (k).
    fit <- kmeans(iris[, 1:4], centers=3, nstart=25)
  • Hierarchical Clustering: Builds a hierarchy of clusters, visualized as a dendrogram.
    d <- dist(iris[, 1:4], method = "euclidean")
    fit <- hclust(d, method="ward.D2")
    plot(fit)

4.3. Classification (Supervised Learning)

  • Splitting Data: First, split your data into a training set and a testing set.
    library(caret)
    trainingIndices <- createDataPartition(iris$Species, p=0.8, list=FALSE)
    trainingSet <- iris[trainingIndices,]
    testingSet <- iris[-trainingIndices,]
  • Decision Tree Model: The rpart package is used to create decision trees.
    library(rpart)
    tree_model <- rpart(Species ~ ., data=trainingSet)
    predictions <- predict(tree_model, testingSet, type="class")
  • Random Forest: An ensemble method that builds many decision trees for higher accuracy.
    # install.packages("randomForest")
    library(randomForest)
    forest_model <- randomForest(Species ~ ., data=trainingSet)
    forest_predictions <- predict(forest_model, testingSet)

4.4. Time Series Forecasting

  • Creating a Time Series Object: Convert your data into a ts object, specifying the frequency.
    # Use the built-in AirPassengers dataset
    air_ts <- AirPassengers
  • Decomposition: Break down a time series into its trend, seasonal, and irregular components.
    decomposed_air <- decompose(air_ts)
    plot(decomposed_air)
  • Automated Forecasting with ARIMA: The forecast package can automatically find the best ARIMA model.
    # install.packages("forecast")
    library(forecast)

    fit_arima <- auto.arima(air_ts)
    forecast_values <- forecast(fit_arima, 24) # Forecast next 24 months
    plot(forecast_values)
